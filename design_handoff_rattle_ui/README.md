# Handoff: Rattle 모바일 앱 UI/UX 재구성 (50개 화면)

## Overview

Rattle은 다매장 손익관리 B2B 앱입니다. 이 핸드오프는 앱 전체(사장님/직원/파트타이머 3개 역할)의 화면을 정보 밀도를 낮추고 내비게이션을 단순화하는 방향으로 재설계한 결과물입니다. 로그인·온보딩(토스 포스 연동 자동화 포함), 홈/대시보드, 재고, 매입·비용, 매출, 인건비·급여정산, 근태, 청소 체크리스트, 설정, 알림까지 포함합니다.

대상 코드베이스: `megaseunghan/rattle` (branch `main`) — React Native + Expo Router, StyleSheet 기반.

## About the Design Files

이 번들에 포함된 `Rattle 재구성.dc.html`은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 입니다. 프로덕션 코드가 아니며, 그대로 복사해서 쓰면 안 됩니다.

작업 방식:
1. HTML을 브라우저로 열어 의도한 화면과 동작을 확인합니다. 화면들이 390px 폭 프레임으로 나란히 배치되어 있고, 각 프레임 위에 `번호 · 화면명 (역할)` 캡션, 아래에 동작 설명 캡션이 있습니다.
2. **기존 리포지토리의 패턴으로 재구현**합니다 — Expo Router 라우트(`app/`), React Native `StyleSheet`, 기존 토큰 파일(`constants/colors.ts`, `constants/designTokens.ts`), 기존 컴포넌트(`lib/components/`)를 그대로 사용합니다.
3. HTML에 하드코딩된 hex/px는 기존 토큰과 대응시킵니다. 대응표는 `design-tokens.md` 참고.

## Fidelity

**High-fidelity (hifi)** 입니다. 색상, 타이포그래피, 간격, 반경, 카피 문구가 모두 최종안 수준으로 정해져 있으므로 픽셀 단위로 재현하는 것을 목표로 합니다. 단, 다음은 목업 한계이므로 실제 구현 시 대체합니다:

- 인터랙션은 대부분 정적입니다(토글·탭·체크박스가 상태 없이 "선택된 모습"으로 그려져 있음). 실제로는 상태를 붙여 동작하게 만듭니다. 화면별 필요한 상태는 `interactions.md`에 정리했습니다.
- 차트는 SVG/막대 목업입니다. 실제로는 리포지토리에서 이미 쓰는 차트 방식을 따릅니다.
- 지도(GPS 기준점)는 자리표시자입니다. 기존 `KakaoMap` 컴포넌트를 씁니다.
- 데이터는 모두 더미입니다(테네스 행궁/영통/광교, 이서연/김민준/박지호 등). Supabase 실데이터로 대체합니다.
