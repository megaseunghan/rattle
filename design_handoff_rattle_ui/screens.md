# Screens

각 화면의 목적 / 레이아웃 / 컴포넌트 / 카피입니다. 공통 컴포넌트 스펙은 `patterns.md`, 색·타이포 값은 `design-tokens.md`를 참조하세요. 여기서는 화면 고유 사항만 기술합니다.

캡션 표기: `번호 · 화면명 (진입 경로) (역할)`

## 인증 / 온보딩

### 35 · 로그인 (데모용)
전화번호 + 비밀번호 로그인. **최종 채택안이 아니며 데모 참고용으로만 남겨둔 화면입니다.** 실제 구현은 37만 하세요.
- 상단 64px 여백 후 로고 52×52 → 헤드라인 "로그인하고 / 매장 손익을 확인하세요" 24px/700
- 필드 2개(전화번호, 비밀번호) → 우측 정렬 "비밀번호를 잊으셨나요?" 12px/600 gray500
- 주요 버튼 "로그인" → 구분선("또는") → 외곽선 버튼 "간편 로그인"
- 하단 고정: "아직 계정이 없으신가요? **회원가입**"(primary)

### 36 · 회원가입 (데모용)
이름 / 전화번호(+인증 버튼) / 비밀번호 / 비밀번호 확인 + 약관 동의. **데모용.**
- 약관: 전체 동의(20px 체크박스, 13px/600) → 구분선 → 개별 3개(18px 체크박스, 13px/500 gray600, 우측 "보기 ›" 12px gray400)
- 필수 2개(서비스 이용약관, 개인정보 수집·이용), 선택 1개(마케팅 정보 수신)
- 하단 주요 버튼 "가입하기"

### 37 · 카카오 소셜 로그인 ← 채택안
카카오 단일 로그인. 최초 로그인 시 자동 회원가입 처리.
- 화면 중앙 정렬: 로고 64×64 → "간편하게 시작하는 / 매장 손익관리" 22px/700 → "카카오 계정 하나로 / 로그인하고 회원가입까지 한 번에" 14px/500 gray500 (모두 중앙 정렬)
- 하단: 카카오 버튼(배경 `#FEE500`, 텍스트 `#191919` 15px/700, 말풍선 아이콘 19px, gap 8px, radius 12px, padding 15px 0) — 라벨 "카카오로 시작하기"
- 그 아래 12px/400 gray400 중앙 정렬: "계속 진행 시 **이용약관** 및 **개인정보처리방침**에 / 동의하는 것으로 간주됩니다" (강조 부분 gray600 600)

### 39 · 매장 참여 (회원가입 다음) (직원)
사장님에게 받은 매장 코드 6자리 입력.
- 헤드라인 "사장님에게 받은 / 매장 코드를 입력하세요" 22px/700, 설명 "매장 설정 > 멤버 관리에서 발급한 6자리 코드예요"
- 코드 입력: 6칸 flex gap 8px, 각 칸 aspect-ratio 1. 입력된 칸(예 `8` `4` `2`)은 `1.5px primary` + `tinted` 배경 + 22px/700 Space Grotesk. 현재 칸은 커서(2×18px primary 바), 남은 칸은 빈 박스
- 중앙 하단 "코드가 없으신가요? **신규 매장 등록하기**"(primary) → 화면 40
- 하단 버튼: 6자리 미완성이면 비활성(`gray200` 배경 + `gray500` 텍스트), 완성 시 활성

### 40 · 신규 매장 등록 (사장님 온보딩)
- 필드: 매장명(placeholder "예: 테네스 행궁") / 업종(칩 3개: 음식점·카페·기타, 기본 음식점 선택) / 주소(검색 필드 + 돋보기 아이콘, 헬프 "직원 출퇴근 GPS 기준점으로 사용돼요") / 사업자등록번호(선택, placeholder "000-00-00000")
- 하단 버튼 "등록하고 시작하기". 등록 즉시 사장님 권한 대시보드 생성

### 43 · 회원가입 - 포스 연동 여부 (신규 매장 등록 다음)
- 헤드라인 "토스 포스를 / 사용하고 계신가요?", 설명 "매장 위치와 영업시간을 자동으로 불러와 / 설정을 간소화해드려요"
- 라디오 카드 2개 (padding 16px, gap 12px):
  - 선택됨: `1.5px primary` + `tinted`. 아이콘 컨테이너 38×38 흰 배경 + 카드 아이콘. 제목 "네, 토스 포스를 써요" 14px/700, 설명 "서비스코드로 연동하고 자동 설정 받기" 11px/500. 우측 20px primary 원형 체크
  - 미선택: `1px gray200`. 아이콘 컨테이너 `gray50` + 연필. 제목 "아니요, 직접 입력할게요", 설명 "주소·영업시간을 수동으로 설정해요". 우측 20px 빈 원
- 하단 버튼 "다음". 미사용 선택 시 화면 17(매장 정보·GPS)로 이동해 수동 입력

### 44 · 서비스코드 안내 · 연동 대기
- 설명 "토스 포스 단말기에서 아래 서비스코드를 / 입력하면 매장 정보가 자동으로 연결돼요"
- 코드 카드: `tinted` radius 16px padding 22px 중앙 정렬 — 라벨 "서비스코드" 11px/600 gray500 → 코드 `BVH3TUFV` 32px/700 Space Grotesk primary letter-spacing .08em → "코드 복사" pill(흰 배경 + `gray200` 테두리 + 복사 아이콘)
- 단계 안내 3개: 원형 번호(22px, `black` 배경 흰 숫자 12px/700) + 설명 13px/500 gray600, gap 12px
  1. 토스 포스 단말기 > 설정 > 서비스 연동 메뉴로 이동해요
  2. 위 서비스코드를 입력하고 연동을 완료해요
  3. 연동이 완료되면 이 화면이 자동으로 넘어가요
- 남은 공간 중앙: 점(8px primary, 펄스 애니메이션) + "연동 대기 중이에요..." 13px/600 gray500
- 하단 텍스트 버튼 "지금은 건너뛰고 나중에 연동할게요"
- 웹훅 도착 시 자동으로 45로 전환, 10분 타임아웃 시 48

### 45 · 연동 완료 · 매장 정보 자동입력 확인
- 상단 중앙: 56px 원형 `tinted` + primary 체크 아이콘 26px → "포스 연동이 완료됐어요" 20px/700 → "아래 정보를 자동으로 불러왔어요 / 필요하면 직접 수정할 수 있어요"
- 정보 카드 2개 (`1px gray100`, radius 14px, padding 14px):
  - **매장 위치 (근태 GPS 기준점)** + `자동입력` 뱃지(positive) → 값 "경기 수원시 팔달구 행궁로 12" 14px/600
  - **영업시간 (매출 마감시각 기준)** + `기본값` 뱃지(중립) → 값 "10:00 - 23:00" → 헬프 "포스에서 영업시간 정보를 받지 못해 기본값으로 설정했어요. 매장 설정에서 바꿀 수 있어요"
- 각 카드 헤더는 아이콘 15px + 라벨 11px/600 gray400 + 우측 뱃지
- 하단 버튼 "확인하고 시작하기"
- 웹훅 `operatingHours`가 null이면 두 번째 카드가 위 모습(기본값 + 안내), 값이 있으면 `자동입력` 뱃지 + 안내 문구 제거

### 48 · 포스 연동 실패 · 재시도
- 중앙: 56px 원형 `#FEE2E2` + negative 경고 아이콘 → "연동 시간이 초과됐어요" 18px/700 → "서비스코드 입력 후 10분이 지나도 / 연동 신호가 확인되지 않았어요"
- 안내 박스(`gray50`, radius 14px, padding 16px): "확인해보세요" 12px/600 gray500 + 불릿 2개
  - 서비스코드 BVH3TUFV를 정확히 입력했는지
  - 포스 단말기가 인터넷에 연결돼 있는지
- 하단: 주요 버튼 "다시 시도하기"(→ 44) + 텍스트 버튼 "나중에 하고 직접 입력할게요"(→ 17)

### 46 · 손익계산서 튜토리얼 (매출 첫 동기화 후)
사장님 대시보드 위에 코치마크 3단계 오버레이. 1단계 디자인만 제공되어 있으므로 2·3단계는 같은 카드 패턴으로 구현합니다.
- 뒤 화면: 대시보드가 blur(1px) + opacity .5
- 카드(top 150px, 좌우 22px): 아이콘 34px `tinted` + 차트 아이콘 → "첫 매출 동기화가 / 완료됐어요!" 15px/700 → "매출·매입·인건비가 자동으로 계산되어 / 실시간 손익계산서로 보여드려요" 13px/500
- 하단: `1 / 3` 12px/600 gray400 (좌) + "건너뛰기"(gray500) + "다음" pill(primary) (우)
- 2·3단계 제안 내용: (2) 월별/연도별 전환과 증감률 읽는 법, (3) 매장별 손익 비교 카드

### 38 · 알림 (홈 벨 아이콘에서 진입)
- 앱바 우측 "모두 읽음" 12px/700 primary
- 필터 칩: `전체 | 근태 | 재고 | 매출` (전체 선택)
- 알림 항목: 아이콘 컨테이너 36×36(radius 10px) + 본문 + 우측 읽지 않음 점(7px primary)
  - **읽지 않음**: 배경 `tinted`, 제목 13px/600 black
  - **읽음**: 배경 없음, 제목 13px/500 gray600, 점 없음
  - 아이콘 배경색: 근태 경고 `#FEE2E2`(negative), 미출근 `#FEF3C7`(warning), 일반 `gray100`(gray)

## 공통 가이드

### 41 · 빈 상태(Empty State) 가이드
4개 패턴이 한 화면에 정리되어 있습니다. 구현 시 각 화면에 해당 패턴을 적용하세요.

| 상황 | 제목 | 설명 | CTA |
| --- | --- | --- | --- |
| 재고 없음 | 등록된 재고가 없어요 | 첫 품목을 등록하면 여기에 표시돼요 | 품목 추가하기 |
| 매출 없음 | 이번 달 매출이 아직 없어요 | POS 연동 또는 직접 등록으로 시작해보세요 | 매출 등록하기 |
| 스케줄 없음 | 배정된 스케줄이 없어요 | 사장님이 스케줄을 배정하면 알려드려요 | 없음 |
| 알림 없음 | 새로운 알림이 없어요 | 근태, 재고, 매출 알림이 오면 이곳에 모여요 | 없음 |

아이콘: 재고=박스, 매출=차트, 스케줄=시계, 알림=사람. 모두 48px 컨테이너 + `gray50` 배경 + `gray400` stroke.
