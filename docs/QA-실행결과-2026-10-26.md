## 차단과 재개 입력

1. **대상/행동:** QA 매장의 후속 직원·급여 입력. **이유:** 로그인 완료 후 재개하여 실제 저장 검증을 확장했으나 이후 Safari/Spotlight로 화면이 바뀌고 ‘사용자가 앱을 변경했다’·AX ID 무효화가 반복됐다. 단순 전경 차이만으로 대기한 것이 아니라 중간 UI 변경이 지속돼 입력 충돌 여부를 질문했다. **상태:** 사용자 조작 종료 확인 대기. 기존 입력·세션은 초기화하지 않음.
2. **대상/행동:** 실제 역할별 참여/반려/제출/RLS 검증. **이유:** 가상 직원에 연결된 별도 기존 테스트 계정 세션이 아직 지정되지 않음. **상태:** 대기. 소유자 미리보기로 대체 불가, 실제 사람 초대/메일 없이 준비된 계정 필요.
3. **대상/행동:** 최신 코드 네이티브 동일성 판정. **이유:** 설치본 1.0.0(1)에 커밋/dirty fingerprint 없음. **상태:** 미검증. 현재 사본 기반 빌드·설치와 소스 해시 기록이 필요.

simctl 최초 읽기 호출은 sandbox에서 CoreSimulator 접근에 실패했으나 읽기 전용 escalation은 승인되어 기기/설치본 정보를 확인했다. 자동 승인 검토에서 거절된 작업은 없다. 부모 thread로 직접 중간 보고를 보내려던 도구는 `thread not found`로 실패했으며 별도 메시지는 전달되지 않았다.
