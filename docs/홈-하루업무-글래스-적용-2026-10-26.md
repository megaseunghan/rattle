# 하루 업무 홈과 GlassMorphism 적용

## 사용자 결정

- 손익 중심 첫 화면을 직원·매니저의 오픈부터 마감까지의 업무 흐름으로 바꾼다.
- 홈 카드·배경·하단 탭바에 GlassMorphism을 적용한다.
- 기존 스플래시 수정본을 배포한다.

## 반영

| 구간 | 연결된 기능 |
|---|---|
| 오픈 준비 | 오픈 체크리스트, 재고 확인, 내 스케줄 |
| 영업 중 | 재고 수량 수정, 권한에 따라 매입 등록·레시피 또는 요일별 체크 |
| 마감 정리 | 마감 체크리스트, 금융 탭 접근이 허용된 역할의 매출 확인·비용 기록 |
| 근무·급여 | 관리자 직원·급여 관리, 직원 본인 명세, 파트타이머 월 실근무 시간 제출 |
| 운영 결과 | 하단 월별 손익 요약을 펼쳐 기존 합계·추이·월 이동 확인. 관리자 상세 손익 연결 유지 |

- 첫 홈은 선택된 매장의 업무 화면이다. 전체 매장 대시보드는 매장 선택에서 계속 사용할 수 있다.
- 실제 오픈·마감 체크 숫자를 사용하고 항목 미등록/조회 실패를 완료로 표시하지 않는다. 날짜는 기존 체크리스트 화면과 같은 로컬 달력 기준이다. 영업일/자정 기준 변경은 이번 범위가 아니다.
- 재고·매입·급여·금융 공유 권한을 확장하지 않는다. 버튼을 누르는 것을 업무 완료로 처리하지 않는다.
- 홈에는 고정 블루 조명 바탕, 반투명 카드·버튼과 흰 경계, 공통 하단 탭바에는 블러 표면을 적용했다. 입력·상세 화면 전체를 일괄 변경하지 않았다.
- iOS 투명도 줄이기와 Android에는 불투명 표면을 사용한다. 투명도 설정 조회 실패 시에도 불투명을 유지한다.
- 공통 FAB는 하단 영역의 실제 높이를 측정해 겹침을 방지한다. 자유 드래그·등록 기능은 유지한다.
- 체크 현황 캐시는 기존 cleaning 도메인의 저장 후 무효화/취소 규칙을 따른다.

## 검증

- typecheck, git diff --check 통과.
- 전체 Jest **67 suites / 420 tests 통과**. 업무 구간 라우팅, 비공유 역할의 금융 버튼 비노출, 조회 실패 표시/재시도, 접힌 손익과 펼친 후 기존 동작, 기본 매장 홈과 명시적 전체 매장 범위를 확인했다.
- 코드 리뷰에서 발견한 FAB 높이와 캐시 키 문제를 수정하고 재검토했다.
- iPhone 16 Pro / iOS 26.3 시뮬레이터의 실제 Release 재빌드·설치로 첫 홈의 오픈/영업 중 카드·글래스 배경·푸터, 하단 마감/급여/손익 카드와 스크롤, 오픈 및 마감 체크리스트 탭 직접 진입·복귀, 손익 펼침, 매출 탭의 FAB·푸터 간격을 확인했다.
- 현재 로그인된 관리자 계정으로 확인했다. 별도 직원·파트타이머 계정 검증은 하지 않았고, 그 권한 분기는 자동 테스트·코드 검토 범위다.
- 운영 자료 저장·체크 변경·새 SQL은 실행하지 않았다. OS 투명도 설정 전환, Android·실제 iPhone 화면 조작, 모든 탭의 세부 화면은 별도 검증 대상이다.
