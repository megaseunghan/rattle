## B. 개인정보처리방침 보완안 (화면 반영용 문안)

최종 수정일 `[적용일]` · 시행일 `[시행일]`

Rattle(운영자: 백승한, 이하 "운영자")은 Rattle 서비스(이하 "서비스")를 운영하며, 「개인정보 보호법」에 따라 이용자의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

### 1. 처리하는 개인정보 항목

| 구분 | 항목 | 수집 방법 |
|---|---|---|
| 회원 가입·로그인 | 카카오·Google·Apple 계정 식별자, 제공에 동의한 이메일·프로필 이름 | 소셜 로그인 |
| 매장 참여 신청 | 신청자 이름, 연락처 | 이용자 입력 |
| 직원 합류 정보 | 고용 형태, 시급 또는 월급, 비과세 금액, 주 근무시간, 입사일, 은행명, 계좌번호 | 직원 본인 또는 매장 관리자 입력 |
| 직원 관리 | 이름, 연락처, 부양가족 수, 수습 여부, 급여 변경 이력, 근무 스케줄 | 매장 관리자 입력 |
| 근무·급여 | 날짜별 근무 분, 근무시간 제출·확인 이력, 급여 계산 결과와 수정 이력 | 이용자 입력·서비스 계산 |
| 매장 정보 | 매장명, 주소, 사업자등록번호(선택), 대표자 연락처(선택), 매출·매입·비용 기록 | 이용자 입력, POS 연동 |

| 자동 생성 정보 | 서비스 이용 기록, 접속 기기 정보(OS 등), 오류 기록 | 서비스 이용 과정 |

### 2. 처리 목적
회원 식별·로그인, 매장 참여·직원 합류 처리, 근무시간 기록과 급여·4대보험 계산, 매장 손익 집계, POS 연동, 문의 대응, 서비스 안정성 확보에 이용합니다. 목적이 바뀌면 사전에 알리고 필요한 동의를 받습니다.

### 3. 보유 및 이용 기간
**출퇴근 기록 추가 문안(2026-11-17 제안·미적용):**

> 출퇴근 기록은 직원 또는 매장 삭제 시 함께 삭제합니다. 출퇴근 기록의 보관 책임은 매장 사업주에게 있으므로 보관이 필요한 자료는 삭제 전에 사업주가 미리 보관해 주세요. 서비스는 출퇴근 기록을 퇴직일 기준 3년간 보관하는 것을 보장하지 않습니다.

이는 조정자가 전달한 사용자 결정에 따른 **보유기간 초안 제안**이며 법률 검토를 마친 문구가 아니다. **노무·개인정보 법적 적합성은 확인되지 않았다.** 직원 삭제와 계정 탈퇴는 구분하며, 아래 매장 공용 자료 전체의 보유 기준을 자동 변경하지 않는다. 기존 “매장 삭제 후 7일 복구”와 출퇴근 기록 동반 삭제·복구 불가 안내의 시점/범위 정합성은 실제 삭제 경로 대조 후 확정해야 한다. 내보내기 기능 구현이나 앱/원격 DB 적용을 뜻하지 않는다.

**아래는 기존 보유기간 문장 이력이다. 출퇴근에 대한 서비스 3년 보관/삭제 차단 해석은 2026-11-17 사용자 결정으로 대체하며, 그 밖의 자료 보유 정책은 이번 과제에서 변경하지 않는다.**
- 회원 계정 정보: 회원 탈퇴 시까지. 외부 로그인 연결 해제가 지연되면 해제 완료 시까지 필요한 식별자만 보관합니다.
- 매장 기록(직원·근무·급여·매출·매입·비용): 매장 공용 기록이므로 개별 회원이 탈퇴해도 매장이 삭제될 때까지 보관합니다.
- 매장 삭제: 매장 소유자가 매장을 삭제하면 **7일 동안 복구할 수 있도록 보관**한 뒤 파기합니다. 복구는 이 기간 안에 앱 또는 문의처로 요청할 수 있습니다.
- 법령상 보존 의무: 근로기준법 등에서 보존 의무가 있는 기록(임금대장 등)의 보존 의무는 해당 매장 사업주에게 있습니다. 매장 삭제 전 필요한 자료를 내려받도록 안내합니다. `[내보내기 기능 유무·보존 주체 해석 — 확인 필요]`

### 4. 파기 절차 및 방법
- 보유 기간이 끝나거나 처리 목적을 달성하면 지체 없이 파기합니다.
- 전자 파일은 복구할 수 없는 방법으로 삭제합니다. 법령에 따라 보존하는 정보는 다른 정보와 분리해 보관합니다.
- 매장 삭제 후 7일 복구 기간이 지나면 해당 매장의 기록을 파기합니다. 기록이 없는 매장은 삭제 즉시 파기합니다.
- 서비스는 별도의 자동 백업 사본을 보관하지 않습니다. `[운영자가 수동 백업(db dump)을 보관하게 되면 보관 기간·파기 시점을 여기에 추가]`

> 검토 메모: Supabase 공식 문서상 무료 플랜은 자동 백업이 없고, Pro 플랜은 최근 7일 일일 백업을 제공한다. 현재 프로젝트는 Nano(무료 플랜 기본 컴퓨트)로 보이나 플랜 자체는 대시보드 Billing에서 최종 확인. Pro로 바꾸면 "백업은 최대 7일 보관 후 순차 삭제" 문구로 바꾼다.
