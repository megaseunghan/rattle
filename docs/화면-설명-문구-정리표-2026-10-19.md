# Rattle 화면 문구 정리표

**상태: 요청한 항목 일부 반영 · 나머지는 검토 초안 · 이번 SQL 변경 없음**

## 이번에 반영한 내용

- 근무시간 입력·저장·정산 화면의 외부 도구 도입/대조 안내와 관련 입력 예시를 제거했다.
- 내부 DB/API 오류 원문은 화면에서 숨기고 실패 여부와 필요한 행동만 표시한다. 입력 누락·권한·동시 수정·중복 신청은 짧은 안내를 유지한다.
- 검토표의 내부 오류 원문 목록과 별도 부록은 제거했다.
- 공통 오류 처리 변경 후 타입 검사와 20개 묶음 116개 테스트를 통과했다. 시뮬레이터의 근무시간 제출 화면에서 안내 제거와 새 예시도 확인했다.

## 남은 문구 검토

최초 조사한 135개 파일·232곳에서 이번 제외 대상 11곳을 빼고 **221곳**을 아래에 남겼다. 이 중 12곳은 새 문구로 반영 완료했으며, 나머지 추천은 아직 적용하지 않았다. ID는 최초 조사 시점과 같고, 줄 번호는 코드 수정으로 달라질 수 있다. 동적 변수는 `{변수}` 등으로 표시한다.

| 처리 | 위치 수 |
|---|---:|
| 삭제 추천 | 24 |
| 짧게 수정 | 93 |
| 수정 필수 | 1 |
| 유지 | 91 |
| 적용 완료 | 12 |
| 합계 | **221** |

## 선택 방법

- [ ] **A. 남은 삭제 추천** 항목을 일괄 제거한다.
- [ ] **B. 남은 짧게 수정** 항목을 제안대로 바꾼다.
- [ ] **C. 남은 수정 필수** 항목을 고친다.
- [ ] **개별 선택**: 유지/삭제할 ID를 적는다. 예: `A+C 적용, C030 유지`.

C175는 계산법을 여는 도움말로 분리하는 UI 변경 후보이므로 단순 문장 삭제에서 분리한다. 입력 단위·조건, 삭제 영향, 급여 재계산·정산 해제, 미입력/0분 구분은 짧아져도 보존한다.

## 범위와 확인 상태

- 현재 라우트에서 참조하는 앱/컴포넌트/훅/서비스의 코드 기반 목록이다. 문구가 여러 위치에 있으면 각각 센다.
- 모든 오류 조건을 실기기에서 발생시킨 것은 아니다. 이번 오류 표시 변경은 정상 입력·미입력·조회 실패·저장 실패·재시도 테스트로 확인했다.
- 원격 DB·기존 기록·입력 검증 및 급여 계산 규칙은 변경하지 않았다.
