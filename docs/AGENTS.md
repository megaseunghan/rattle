## For AI Agents

### Working In This Directory

- `private/`는 로컬 세션 전용이다. 커밋·푸시·PR 본문·첨부에 넣지 않고, `git add -f`로 우회하거나 공개 문서로 내용을 복사하지 않는다. 다른 체크아웃에 없으면 전달됐다고 가정하지 않는다.
- 화면 ID `Sxx`/`Mxx`/`E-Sxx`/`C01~C09`는 재사용하며 정렬 때문에 다시 매기거나 삭제 ID를 다른 기능에 쓰지 않는다. 새 화면은 새 ID로 추가하고 명세·E2E·manifest를 함께 갱신한다.
- 새 배포·검증 이력과 긴 참고표는 루트 `AGENTS.md`가 아니라 관련 문서(주로 `에이전트-제품결정-기술참고.md`의 해당 절이나 기능 문서)에 적는다.
- 날짜가 붙은 완료 기록·QA 로그는 당시 기록이다. 현재 서버·설치본의 검증 증거로 인용하지 않는다.
- 에이전트 참고 문서 두 개는 전체를 매번 읽지 말고 작업 관련 절만 읽는다. 현재 체크아웃에서 추적 상태가 다를 수 있으니 `git status`로 확인한다.
- 단발성 기록이 끝나면 `archive/YYYY-MM/`로 옮기고 `archive/README.md` 목록을 갱신한다. 미검증 범위·후속 조치는 삭제하거나 완료로 바꾸지 않는다.
- 진행 상태는 `workspaces/README.md`가 안내하는 작업계획 MD에서만 관리한다. 중복 진행표를 새로 만들지 않는다.

### Common Patterns

- 파일명 `주제-YYYY-MM-DD.md`, 제목에 기준일·상태(초안/미적용/v2 등) 표기.
- 실행 상태는 통과/실패/차단/미실행으로 구분하고 미실행을 통과로 바꾸지 않는다.
- 시안 폴더는 하나의 `design-state.md`로 결정을 기록한다(`.agents/skills/rattle-design-dialogue/SKILL.md`).
