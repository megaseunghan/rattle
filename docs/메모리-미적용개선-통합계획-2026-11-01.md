- 현재 작업본에는 이미 다수 미커밋/미추적 변경이 있었다. 새 브랜치는 동일 작업본을 보존하며 생성했다. 브랜치 포인터만으로 미커밋 변경이 보관·격리되지는 않는다. 이번 문서와 수정도 아직 미커밋이다.

- 담당: 주 에이전트가 목록 통합·구현·로컬 QA를 담당. 독립 코드 리뷰는 별도 검토자가 이번 수정의 시작 사본과 비교한다. 실제 기기/JWT 검증은 미실행.
- 기계가 읽을 목록: [JSON](memory-improvements-2026-11-01.json). 기존 U01~U34/Sxx/Mxx ID를 유지했다.

이번 수정 파일: `app/mypage/payslip.tsx`, `lib/hooks/useNotificationSettings.ts`, `app/notifications/settings.tsx`, `app/settings/store.tsx`, `app/settings/sales.tsx`. 새 회귀 테스트 3파일(PayslipRecovery, useNotificationSettingsRecovery, StoreSettingsRecovery)과 병행 작업의 PayslipScope 테스트를 함께 검증했다. 기존 dirty 변경 전체를 이번 구현 성과로 세지 않는다.

## 제외와 한계

- 출퇴근/GPS, 평가/인센티브, 발주 화면, OCR, 이름 변경, 취소된 연간 로딩 진단은 자동 개발 대상에서 제외.
- 예약 API·도메인 구매·최종 DB 변경은 조사/선택 단계. 확정된 앱 개선과 섞지 않는다.
- 실제 기기/Android/원격 업무 검증을 문서·mock·시뮬레이터 관찰로 대신하지 않는다. 외부 서비스의 현재 기능/법률 적정성을 이번 메모리 조사로 재인증하지 않았다.
- 다른 과거 세션이 메모리 등록에서 빠졌을 수 있다. 이 목록은 확인 가능한 18개 세션 요약·현재 소스·저장소 기록의 합집합이다.
- 기존 변경의 코드/SQL은 이 브랜치에 자동 커밋되지 않는다. 작업 시작 사본은 `/private/tmp/rattle-memory-improvements-baseline/`에 이번 수정 대상 5파일만 저장했다. 비밀 환경파일은 복제하지 않았다.
