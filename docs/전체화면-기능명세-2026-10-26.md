## 현재 경계와 미확정 사항

1. **단위 확장:** 재고 기준 단위는 kg/g/L/ml/oz/개. 기존 mL도 환산 호환한다. oz는 무게 온스이며 fl oz(액량 온스)가 아니다. 1oz=28.349523125g. 저장 당시 수량·단가를 자동 재작성하지 않는다. `20261102010000_inventory_unit_ounces.sql`은 로컬 작성·격리 확인 상태이며 이번 원격 적용 미실행이다. oz 사용 전 서버 환산 함수 적용을 확인한다. 단위 변경 시 기존 수량/단가의 환산·확인 UX는 별도 보완 대상이다.
2. **숫자 입력:** 단위 추가가 U20/U21 해결을 의미하지 않는다. 재고의 parseFloat/0 대체와 레시피 재료별 양수·유한수 검증은 아직 보완 대상이다. 매입 신규 단가 0 허용/상세 수정 0 거부(U22)도 정책 미확정이다.
3. **급여 보존:** 명세는 저장된 gross·taxable_base·공제로 설명하고 현재 직원 조건으로 과거 명세를 다시 해석하지 않는다. S05의 재직자 필터로 과거 퇴사자 명세 접근(U11)은 남아 있다. 일별·월 제출·급여 반영·정산을 하나의 완료 상태로 합치지 않는다.
4. **저장 성공과 갱신 실패:** 수기매출·매장/영업일 설정은 쓰기 성공을 유지하고 읽기를 재시도한다. 요청 승인·삭제의 결과 불명은 기존 자료를 보존하고 재조회 전 반복 쓰기를 막는다. 정산 서비스의 반환 ID 검사는 전체 성공 오인을 방지하지만 모든 화면의 부분처리 UX 완료를 뜻하지 않는다.
5. **권한:** PT는 레시피 조회와 재고 수량 수정만, 관리 기능은 확인된 관리자/정규직 중심이다. 직접 경로 및 RLS/누적 정책·SECURITY DEFINER는 실제 역할 세션으로 별도 확인한다. 로컬 권한 SQL 존재만으로 원격 적용/안전성을 확정하지 않는다.
6. **Apple/참여:** 로그인에 Apple 버튼이 플랫폼 분기 없이 존재하며 서비스는 iOS 네이티브/그 외 OAuth 분기다. AGENTS의 iOS 한정 결정과 U10을 대조해야 한다. 직원 신청은 현재 참여코드 흐름이며 사업자번호 필수 입력이라는 옛 설명을 사용하지 않는다. 동일 이메일 소셜 계정 연결 정책·Provider 탈퇴도 별도 확인이다.
7. **이동·취소:** 홈→손익의 선택 월 미전달(U32), 대시보드 period와 상세 yearMonth 계약(U33), 읽음 성공 후에만 업무 진입하는 홈 알림(U27), 청소 드래그 실패 복원(U28)은 남은 과제다. useConfirmLeave는 OS 강제 종료 후 영속 초안 복구를 보장하지 않는다.
8. **상세 복구·검색:** 레시피 상세 재시도는 구현돼 있으나 매입/재고 상세 재시도는 부족하다. 품목 선택기의 검색은 로드 자료 중심이고 매입은 startsWith다. 재고 탭 레시피와 독립 목록의 페이지/오류 차이가 남아 있다.
