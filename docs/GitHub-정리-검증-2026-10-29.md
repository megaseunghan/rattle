- 경쟁 서비스 관련 비공개 조사·이미지·보고서는 로컬에서 보존한다.

- 로컬 도구 로그, 서명키·백업·환경파일, 스토어 이미지 중복 폴더·ZIP과 이전 세트는 제외한다.
