## 보관 기준

- 구현·점검·설치·배포 작업의 결과가 남은 단발성 기록은 `archive/YYYY-MM/`에 보관한다. 기존 미검증 범위와 후속 조치는 삭제하거나 완료로 바꾸지 않는다.
- 현재 명세·운영/SQL 적용 안내·미해결 감사/계획·진행 중 QA와 작업소 지시문은 유지한다. 향후 후속 작업이 끝나면 다시 판정한다.
- 담당별 작업계획 6개로 통합된 중복 계획·진행표는 수용 기준 이전을 확인한 후 삭제한다. 실제 검증·배포 증거와 현재 명세·설정 안내는 유지한다.
- 비공개 자료와 스토어 제출 자산은 이번 정리 범위 밖이다. 커밋/푸시/배포는 별도 요청이 있을 때만 진행한다.

전문 작업소의 작업계획 원본은 [작업소 안내](workspaces/README.md)의 실제 경로에 있다. 중앙의 동일한 배포용 MD 6개와 통합된 과거 진행표 4개는 삭제했다.
