# 요일별 체크리스트 추가 즉시 동기화 hotfix

## 문제와 변경

사용자 보고: 요일별 체크리스트 편집창에서 항목을 추가해도 화면에 바로 보이지 않는다.

소스 기준: `feature/operations-workflows` / `0d04e7860ed7b72af933854e5d347a7b8a23bb09` + 기존 dirty 작업본. 대상 S10 체크리스트 편집, S11 체크리스트. 현재 원격 최신 여부 미조회. 기존 10/30 UI 변경을 보존했다.

코드에서 편집창·체크리스트가 훅별 별도 items/logs 상태를 가지고, 진행 중 조회 결과가 저장 후 목록을 덮을 수 있는 경로를 확인했다. 새 행이 목록 밖에 생기거나 키보드가 첫 탭을 소비하는 상황도 함께 보완했다. 사용자의 실제 설치본에서 같은 원인을 재현한 것은 아니다.

- `lib/hooks/useCleaningChecklist.ts`: 계정·권한·미리보기·매장별 TanStack Query items 캐시와 날짜별 logs 캐시 공유. 저장 성공 결과를 공유 캐시에 반영하기 전 진행 중 조회 취소. 저장 실패에는 가짜 항목을 만들지 않음. 매장/계정 전환 시 다른 키로 분리. 빈 배열 참조를 고정해 편집 목록 동기화 effect의 반복 렌더 방지.
- `app/cleaning/edit.tsx`: 키보드가 열린 상태에서도 추가 버튼에 탭 전달, 저장 성공 시 키보드 닫기 및 새 항목 위치로 스크롤, 미측정 행은 최대 3회 재시도, 구분/계정 전환·대상 삭제 시 이전 이동 취소, 같은 렌더 내 추가 연타 ref 잠금. 최초 목록 조회 미확보 시 추가 차단과 재시도 안내.
- 기존 요일 값은 유지한다. 편집창은 전체 요일 항목을 표시하고, 실제 실행 체크리스트는 오늘 요일의 항목만 표시하는 기존 규칙을 유지한다. 다른 요일에 추가한 항목을 오늘 업무로 바꾸지 않는다.

새 SQL/스키마/정책/Realtime 구독을 추가하지 않았다. 이 수정은 같은 앱 세션의 화면 간 동기화이며 다른 기기에 대한 실시간 푸시 동기화를 구현한 것은 아니다.
