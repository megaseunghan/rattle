## 검토 후 유지한 항목

- GlassCard의 기존 테두리·그림자: 승인된 글래스 토큰을 유지한다.
- 버튼 scale(0.96): 반복 업무와 시스템 동작 줄이기 대응을 고려해 이번에는 기존 opacity 피드백을 유지한다.
- 웹 전용 text-wrap/font-smoothing: 네이티브 공통 부품에 CSS 스타일 체계를 추가하지 않는다.
