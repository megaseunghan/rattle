# 월별 손익 상세 하단 잘림 수정

## 원인과 변경

- 기존 Release 앱의 iPhone 16 Pro 시뮬레이터에서 마지막 영업이익 행이 잘리고 본문을 스크롤해도 전체 금액이 드러나지 않는 현상을 재현했다.
- 시트가 중첩 Pressable에 감싸져 있고, 백분율 최대 높이와 내부 ScrollView의 높이 제한이 올바르게 연결되지 않았다.
- 배경 닫기 영역을 시트와 형제로 분리했다. 시트가 화면 높이를 직접 기준으로 최대 88%까지 차지하고, 내용이 적으면 자연 높이를 사용한다. 본문에 flexShrink를 적용해 제목을 고정한 상태로 스크롤 영역이 줄어들게 했다.
- 홈 인디케이터 안전영역과 본문 하단 여백을 확보하고 닫기 버튼을 44pt로 늘렸다. 스크롤 표시기를 기본 표시한다.

## 검증

- `npm run typecheck` 통과.
- `ProfitLossScreen.test.tsx` 6개 테스트 통과. 월 상세 열기, 본문 터치 후 유지, 닫기, 다른 월 재진입, 배경 닫기 회귀를 포함한다. Jest는 실제 스크롤 레이아웃을 검증하지 않는다.
- 최종 소스로 iOS Simulator Release 재빌드·설치·실행 성공. iPhone 16 Pro / iOS 26.3에서 실제 조회된 10월 상세의 영업이익 행·금액이 하단에서 잘리지 않는 것을 확인했다. 본문 스와이프 후에도 전체 행이 보이며, 배경 닫기와 5월 재진입·닫기 버튼을 확인했다.
- 이때 조회된 상세는 모두 화면에 들어오는 길이였다. 다수 매입 분류가 있는 긴 내역·큰 글자·가로 화면·물리 iPhone의 제스처는 검증하지 않았다.
- 코드 리뷰에서 차단 결함 없음.

## 배포 상태

- 물리 iPhone 설치본은 이 수정 이전 버전이다. 사용자가 직접 Release 빌드 → 기기 설치 → 실행하면 반영된다.
- SQL 변경은 없다.
- 타입 검사에 잘못 포함되던 원격 함수 백업을 비공개 폴더 내에서 `.ts.txt`로 이름만 바꿨다. 내용은 보존했다.
