|---|---|

| Tab | React Navigation Tabs가 아닌 PagerView. 기존 visited.has(idx) 조건이 방문 전 마운트를 막는 lazy 동작. lazy 옵션을 지원하지 않는 PagerView에 전달하지 않았다. 방문한 탭의 폼/스크롤 상태는 보존한다. |

| 상태 공유 | Auth·매장·선택 월·업무 복귀 범위는 필수 공유 상태로 유지. 화면 폼은 기존 로컬 상태. 일괄 언마운트로 입력값을 초기화하지 않는다. |

설치된 native-stack 타입에는 freezeOnBlur가 있고 unmountOnBlur는 없다. freeze는 언마운트/메모리 해제가 아니며 타이머나 effect를 중단하지 않는다. 화면을 떠날 때 중단할 작업은 focus cleanup으로 처리해야 한다.

## 비동기·정리 감사

app/lib의 모든 setTimeout/setInterval/requestAnimationFrame/addListener/addEventListener 호출을 검색하고 소유자·cleanup을 대조했다.

| 위치 | 조치/확인 |
|---|---|
| 매입 등록 validate 지연 포커스 | 이전 timeout 취소 후 재예약, unmount clearTimeout |
| 급여조건 focused field rAF | 이전 프레임 취소·unmount 취소, 단계 변경 스크롤 프레임 cleanup |
| AuthContext auth event | 지연 loadStores timeout을 다음 인증 이벤트/unmount 때 취소. Supabase 콜백 밖으로 미루는 기존 잠금 회피와 요청 버전 검사 유지 |
| POS 연결 대기 | useFocusEffect로 폴링 종료, blur/unmount 시 진행 중 응답 무효화 및 in-flight 잠금 해제 |
| 루트 OAuth 링크 | 초기 URL promise와 늦은 오류 알림에 active 검사, 링크 listener 제거 |
| 홈 초기 보조 새로고침 | scheduleIdleTask로 idle 시점에 시작. active 변경/unmount 시 대기 작업 취소. idle API 없으면 setTimeout(0) fallback. 사용자 수동 새로고침은 기존 즉시 동작 |
| Auth 권한 재조회 | 기존 interval clearInterval + AppState subscription.remove 확인. 권한 철회 반영은 지연시키지 않음 |
| 알림 폴링 | 기존 focus 구독 해제·마지막 subscriber clearInterval 및 lifecycle unsubscribe 확인 |
| Query focus manager | 기존 AppState listener.remove 확인 |
| 이탈 방지 | 기존 beforeRemove unsubscribe 확인 |
| 투명도 접근성 | 기존 listener.remove + async active 검사 확인 |
| 지도 | WebView ready timeout clearTimeout 확인. HTML 내부 message/지도 listeners는 해당 WebView 문서 수명에 속함 |
| QA 로그인 | fetch abort timeout은 기존 finally clearTimeout 확인 |
| 기존 SheetModal/손익 모션 | 기존 Reanimated UI 스레드 모션 및 cancelAnimation 유지 |

RN 0.83 InteractionManager는 deprecated이므로 새로 추가하지 않았다. requestIdleCallback timeout=500은 기아 방지를 위한 상한이며 전환 완료 보장이 아니다. idle/timeout은 JS 실행 시점만 나누며 다른 쓰레드로 계산을 이동하지 않는다. 긴 동기 연산을 단순 timeout으로 감싸 프레임 개선으로 주장하지 않는다.
