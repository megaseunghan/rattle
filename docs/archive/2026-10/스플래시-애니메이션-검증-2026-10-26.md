# 스플래시 애니메이션 — 2026-10-26

사용자가 제공한 SplashScreenGuideRattle.png를 기준으로 실제 React Native 시작 애니메이션을 구현했다.

## 후속 수정: 끊김을 줄인 연속 변형 (최신 설치본)

사용자의 단계별 끊김 피드백에 따라 아래 초기 1.2초 구현을 교체했다.

- 하나의 1.8초 UI 스레드 시간축에서 같은 구조의 SVG 곡선을 연속 보간한다. 덩어리·분리 조각·최종 이미지 사이의 교체와 짧은 스프링을 없앴다.
- 형태 변형, 크기·위치 이동, 글자 등장을 겹쳐 이어 붙이고 구간 양 끝의 속도·가속도가 0인 보간을 사용한다. 화면 퇴장은 별도 0.22초다. 초기화·인증 대기는 별도이며 동작 줄이기 대응을 유지한다.
- `npm run typecheck`, `git diff --check`, 스플래시 테스트 2 suites / 9 tests 통과. 곡선의 닫힘·유한 좌표·동일 구조·인접 시점 연속성을 검사했다. 수학적 연속성 검사는 실제 60fps 측정을 의미하지 않는다.
- 코드 리뷰 후 iOS Release 시뮬레이터·실기기 빌드 성공. 전용 Rattle Motion QA(iPhone 16 Pro / iOS 26.3)에 설치하고 시작→로그인 진입을 녹화했다. 18.3 / 18.6 / 18.9 / 19.2초 영상 프레임에서 형태 변화·로고·글자·퇴장을 확인했다.
- 원본 `/private/tmp/rattle-splash-fluid-qa.mov`, 미리보기 `/private/tmp/Rattle-Splash-Fluid-Preview.mp4`.
- 서명 검증 후 승한의 iPhone에 업데이트 설치 성공. 응답 `/private/tmp/rattle-splash-fluid-device-install.json`, 번들 SHA-256 `9a3240ab9b6474408c074a186cd671ee5414a6ffc3d348fc3318c4055144ef8e`.
- 하루 업무 홈·글래스 UI를 포함한다. 실기기에서 느끼는 부드러움과 프레임 성능, Android, TestFlight/App Store는 검증하지 않았다. SQL 변경 없음.

## 초기 구현 (아래는 교체 전 기록)

- 0–0.3초: 블러 처리된 유기적인 파란 블롭 등장.
- 0.3–0.6초: 세 조각으로 분리하며 위치·각도·비율 변화.
- 0.6–0.8초: R 형태로 정렬, 기존 원본 로고로 교차 전환.
- 0.8–1초: damping 12 / stiffness 200 스프링과 옅은 원형 후광.
- 1–1.2초: 로고를 조금 줄이고 Rattle 글자와 짧은 장식 바 등장.
- 본 시퀀스는 1.2초이며, 앱으로 넘어가는 페이드 0.12초가 별도로 있다. OS/JS/폰트 초기화 시간과 인증 대기는 이 시간에 포함되지 않는다.
- 네이티브 화면은 흰 바탕으로 이어지고, JS 화면 준비 후 인증 완료를 기다리지 않고 애니메이션을 시작한다. 인증이 늦으면 완성 로고를 유지한다. 장식 바는 네트워크 진행률을 나타내지 않는다.
- 동작 줄이기 설정에서는 변형·이동·스프링을 생략하고 완성 로고를 0.15초 페이드한다.
- UI 스레드에서 transform/opacity를 갱신한다. 블러는 SVG 고정 필터이며 프레임마다 강도를 변경하지 않는다. 물리 유체 시뮬레이션 대신 블롭과 조각의 교차 전환을 사용한다.
