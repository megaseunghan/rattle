# 매장 참여 요청 알림

> **현재 상태 · 2026-10-23:** 참여 알림 함수의 원격 본문 일치를 확인했다. 이미 존재해 해당 파일을 재실행하지 않았다. 아래 미적용 서술은 당시 기록이다. 최신 근거는 [SQL 원격 적용 확인](SQL-원격적용-확인-2026-10-23.md)을 따른다.

신규 신청은 관리자 계정의 홈 종 아이콘 → 알림 → 매장 참여에 표시한다. 알림을 누르면 멤버 관리로 이동한다. 승인·거절 시 해당 알림은 읽음 처리하며, 재신청은 같은 알림을 새 시각의 안 읽은 상태로 갱신한다. 기존 승인 대기도 SQL 적용 시 알림으로 등록한다.

기존 승인 요청 팝업은 제거한다. 홈과 알림 화면이 활성화된 동안 30초마다 갱신하고, 화면 진입·앱 복귀 시에도 조회한다. 휴대폰 푸시는 포함하지 않는다. 읽음 상태는 기존 알림과 동일하게 매장의 관리자끼리 공유한다.

## Supabase 적용

원격 DB에는 아직 적용하지 않았다. 기존 20261019 및 20261020 마이그레이션 적용 이후 아래 파일을 1회 실행한다.

1. `supabase/migrations/20261021_member_request_notifications.sql`

SQL 적용 후 앱을 새로고침한다. 네이티브 모듈 변경은 없다.

## 로컬 확인

- `npm run typecheck`
- `npm test -- --runInBand --no-coverage`
- `node scripts/validate-member-notifications-sql.mjs`

SQL 검사는 축약 스키마를 사용하는 로컬 PGlite 검증이다. 실제 서버·계정·기기 검증을 대신하지 않는다. 적용 후 직원 신청 → 관리자 알림/배지 → 알림 선택 → 승인/거절 → 읽음 반영, 일반 직원 계정에서 참여 알림 비노출을 확인한다.
