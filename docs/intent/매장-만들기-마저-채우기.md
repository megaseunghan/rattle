# 매장 만들기 · 마저 채우기 · 홈 유도 (의도 확정본)

**확정:** 2026-11-27, 사용자 확인 (grilling Q1~Q21, Q17-1). 사용자가 "A로 가자"며 시안 작업을 이어가기로 함.
**관련 화면:** S02 매장 선택·생성(M01 StoreSetupWizard), S04 매장 홈 알림, S35 멤버·합류 승인, S38 일 정산 시간, S39 매장 정보
**짝 문서:** `급여-계산-바로잡기.md` (B, 별도 진행)

## 목표 (Why)

- 가입 직후 이탈하지 않게 매장 만들기에서는 꼭 필요한 것만 받는다. 처음부터 많이 쓰게 하면 사용자가 떠난다.
- 급여·세무·노무 정보는 매장을 만든 뒤 홈에서 안내해 '마저 채우기'로 받는다.
- 24시 매장, 상시근로자 5인 기준처럼 실제 매장의 경우의 수를 빠뜨리지 않는다.
- 이 정보는 우선 **기록과 안내**에 쓴다. 앱의 자동 계산은 실제 지급과 다를 수 있으므로 계산 반영은 B와 그 다음 단계에서 다룬다.

## 정한 것

**매장 만들기 흐름**
- 순서: 매장 이름 → 주소(선택) → 마감 시간 → 손익 공유 → 수습 기간 → 매장 시작하기 → 멤버 초대.
- 한 화면에서 '다음'을 누르면 다음 질문이 아래에 나타난다. 답한 질문은 작게 줄어들고 그 자리에서 고칠 수 있다.
- 흰 바탕, 입력은 밑줄, 진행 막대는 끊김 없는 한 줄, 위 왼쪽 뒤로 화살표만(단계 글자 없음).
- 고른 항목은 배경색(연파랑)으로 표시한다. 라디오 원은 쓰지 않는다.
- POS 연결 단계와 요약 단계는 없앤다. POS 연결은 매장 설정에서 시작한다.
- 주소: 선택. 비어 있으면 버튼이 '건너뛰기'.
- 마감 시간: 휠(오전/오후 + 1~12시, 현재 앱 일 정산 시간 휠과 같은 모양). 오전 1~5시는 '다음 날 오전 n시', 오전 12시는 '자정'으로 표시. 안내는 "○○에 닫아요." 한 문장.
- 24시간 영업: 고르면 하루 매출을 나눌 시각을 따로 묻는다(기본 오전 6시).
- 손익 공유: 처음엔 아무것도 고르지 않은 상태, 고르기 전엔 다음 버튼이 꺼짐.
- 수습 기간: 없음(기본) / 1개월 / 2개월 / 3개월. 설명은 "입사일부터 계산돼요. 나중에 바꿀 수 있어요." '직접 정하기(일 단위)'는 두지 않는다(2026-11-27 변경). 법 기준은 '90일'이 아니라 '수습 시작일부터 3개월 이내'라 입사일에 따라 89~92일로 달라지기 때문이다. 마지막 날 = 입사일에서 N개월 뒤 같은 날의 전날, 그 달에 같은 날이 없으면 그 달 말일.
- 수습 비율(2026-11-27 추가 결정): 기간을 고르면 바로 아래 "수습 중 급여는 몇 %로 줄까요?" 입력칸(전체 폭 밑줄, 90 미리 입력, 1~100%, 90이면 오른쪽에 '기본값')이 이어진다. 입력하면 "예: 시급 ○원이면 수습 중 ○원이에요"를 바로 보여 준다. '수습 없음'이면 나오지 않는다. 매장 기본값이다.
- 합류 승인 '수습 적용' 시트(직원별): 적용해요/적용 안 해요 → '수습 마지막 날'(1·2·3개월 빠른 선택 + 달력, 입사일부터 3개월이 끝나는 날까지만 고를 수 있음, 처음엔 매장 기본 기간으로 계산한 날) → '수습 중 급여' %(매장 기본값 미리 입력, 바꾸지 않으면 '매장 기본값' 표시) → 결과 안내 → 1년 미만·단순노무 참고.
- 수습 비율 적용 결과가 최저임금의 90%보다 적으면: 정한 비율 그대로 계산하고 막지 않는다. 합류 승인 수습 시트와 직원 명세서에 회색 안내 "최저임금의 90%보다 적어요. 수습이어도 이보다 적게 줄 수 없어요."를 띄운다. 1년 미만 계약·단순노무는 수습 감액이 안 된다는 참고 안내는 유지.
- 멤버 초대 화면: 매장을 만든 직후. 참여코드 복사하기·공유하기, 홈으로 가기. 코드 기한 없음(대신 멤버 관리에서 새로 만들면 예전 코드 폐기).

**마저 채우기 (사장님만 수정, 점장은 보기만)**
- 급여 마감일·지급일: 한 줄 두 개 + 누르면 아래 시트 날짜 판(1~29일·말일, 30·31일은 취소선).
- 지급일이 주말·공휴일이면: 앞당겨서(기본) / 그날 그대로 / 미뤄서.
- 5인 이상 여부: 사장님이 고름(5인 이상 / 5인 미만 / 잘 모르겠어요). 앱은 최근 한 달 기록으로 참고 숫자만 보여 준다.
- 사업자 유형(개인/법인, 일반/간이과세)과 사업자번호.
- 4대보험 가입 사업장 여부(예/아니오).
- 산재보험 업종(2026-11-27 시안 fill-v5): '가입했어요'를 고르면 바로 '어떤 업종인가요?' 시트가 이어진다. 보기는 도소매·음식·숙박업 / 목록에 없어요. 4대보험 묶음은 '아직이에요' 또는 '가입 + 업종'이어야 채운 것으로 센다.

**직원 합류 (2026-11-27 시안)**
- 매장 만들기와 같은 방식: 한 화면에서 답하고 '다음'을 누르면 아래에 다음 질문, 답한 질문은 작게 줄고 눌러 고침, 마지막 확인 단계 없음, 마지막 버튼 '관리자에게 제출'.
- 순서: 이름 → 휴대폰 번호 → 근무 형태 → 계약(근로자/일용근로자/프리랜서 3.3%/잘 모르겠어요) → 시급 → 주휴수당(따로/시급에 포함/잘 모르겠어요, 파트타이머만) → 주 근무시간 → 입사일 → 은행 → 계좌번호. 월급제는 시급·주휴·주 근무시간 대신 월 급여·비과세.
- 입사일은 년·월·일 휠(1970년~), 주 근무시간은 시간+분(10분 단위) 휠, 은행은 소제목 없는 4열 버튼(순서: 인터넷은행 토스·카카오·케이 → 1금융 → 2금융, 맨 끝 '직접 입력').
- 관리자 합류 승인(확정): 줄 + 아래 시트 방식(급여·세금·수습·계좌 묶음, 입사일·주 근무시간 휠, 계좌 시트는 화면 높이까지 은행 4열 버튼 + 계좌번호), '직원이 고름' 표시, 계약이 '잘 모르겠어요'면 관리자가 정해야 최종 합류, 최저임금 미달은 회색 안내(막지 않음), 수습 적용 시트. 주의 표시에 노란색을 쓰지 않는다.

- 직원은 모두 참여코드로 합류 신청 → 관리자 승인으로만 들어온다(2026-11-27 사용자 결정). 관리자가 직접 '직원 추가'하는 화면은 두지 않는다. 합류 외에 직원을 연결하는 화면을 따로 만들지 않는다. 단, 일용근로자는 합류 신청으로 오지 않고 매장이 일용근로자 급여대장에서 직접 추가한다(하루면 끝나므로). 합류 계약 보기와 직원 정보 소득 구분에서 '일용근로자'는 뺀다.
- 직원 정보(수정) 시안 emp-v2: 합류 승인과 같은 줄 + 아래 시트, 시트 확인 = 그 항목 바로 저장. 근무 형태는 고치지 않음. 시급·월급은 '바꾸기' 시트(오늘부터/다음 급여 기간부터). 소득 구분 근로자/프리랜서 3.3%. 부양가족 −/+ 버튼. 계좌는 끝 4자리 + '계좌 보기', 바꿀 때만 새 번호 입력.
- 화면 문구에 서버 처리·암호화 보관 같은 내부 동작이나 부연 설명을 쓰지 않는다(2026-11-27 사용자 결정).

- S54 일용근로자 급여대장 시안 s54-v2(2026-11-27): 명단은 매장에서 직접 추가(합류 없음). 앱은 돈을 보내지 않고 상태만 기록한다: 근무 기록은 '지급 대기'로 쌓이고, 골라서 '지급 완료로 바꾸기' → 지급일·지급 방법(계좌이체/현금)·공제(소득세·지방소득세·고용보험, 예상값을 채우고 눌러서 실제 금액으로 고침) → 완료. '지급하기·지급 처리'처럼 송금하는 듯한 말은 쓰지 않는다. 완료 내역에서 '지급 대기로 되돌리기'. 한 달 8일 이상이면 국민연금·건강보험 대상 안내 한 줄.

**홈 유도와 알림**
- 홈 유도(2026-11-27 시안 결정): 다 채우기 전에는 **하루 한 번, 그날 처음 홈을 열 때** 채우기 바텀시트("매장 정보를 마저 채워 주세요" + 채움 칩 4개 + 채우기/나중에 할게요)를 먼저 띄운다. '나중에 할게요'면 같은 내용이 알림 카드 묶음 맨 위에 남는다(아무것도 안 채웠으면 "급여 마감일·지급일을 정해 주세요 / 정하면 월급날 3일 전과 당일에 알려 드릴게요", 일부 채웠으면 "4개 중 n개 채웠어요"). 4개를 다 채우면 시트·카드 모두 사라진다.
- 마저 채우기 화면: 4묶음(급여 날짜·직원 수·사업자·4대보험), '4개 중 n개' 진행, 안 정한 줄은 회색 '아직 안 정했어요'(누르면 아래 시트에서 정함), 고르면 바로 저장. 제목 아래 설명은 안 채운 항목 중 하나의 쓸모를 화면을 열 때마다 무작위로 보여 주고, 다 채우면 마무리 문구.
- 설정 후 앱 안 알림만: 지급일 3일 전 "3일 뒤 월급날이에요", 당일 "오늘은 월급날이에요". 받는 사람은 사장·점장.

- 산재 업종·사업장관리번호 등 신고용 정보.
- 주소 검색, 휴게시간 입력.
- 급여 계산 변경(B 문서), 연장·야간·휴일 가산 자동 계산.
- 시안 확정 = 앱 구현 승인이 아니다.

## B에서 넘어온 디자인 작업 (2026-11-27, 인계)

B(급여 계산 바로잡기, 브랜치 `fix/payroll-calculation`, 미커밋)의 원격 SQL 6개(`20261127120000`~`125000`)는 2026-11-27 적용·재조회 확인됐다. 앱 배포(시뮬레이터 확인·iOS preview EAS)는 사용자 결정으로 **A 디자인 확정 후 함께 한 번에** 한다. B 코드·결정은 B 브랜치의 `docs/intent/급여-계산-바로잡기.md` 「교차검증 후 결정」 참고.

3. **직원 폼·합류 승인의 새 필드 정식 디자인**: 소득 구분(근로자/프리랜서 3.3%), 주 근무시간(시간+분), 주휴 포함 여부, 수습 마지막 날, 계좌번호(암호화 보관, 끝 4자리 표시, 바꿀 때만 입력). B는 기존 폼에 최소 필드만 붙여 둠.

- 정산 화면: 주 근무시간이 비어 공제 없이 계산된 직원은 확정 전 알림(막지 않음), 계좌 보기.
- 앱 배포 전까지 설치된 이전 앱은 직원 계좌번호 칸에 암호화 토큰(`enc:v1:…`)이 보인다. 배포를 오래 미루지 않는다.
- 화면 ID: S53은 삭제된 OCR 화면이라 재사용하지 않는다. 일용근로자 급여대장은 S54.
