# 노션 기능 기준 기록 시범 (의도 확정본)

**확정:** 2026-11-21, 사용자 명시적 "네" (interview-me)

## 목표 (Why)

혼자 여러 세션에서 서로 다른 작업을 너무 많이 돌려 사용자가 마지막 검토를 하지 못했다. 그 결과 What(화면·행동·API)만 있고 Why(왜 만드는지·사용자 의도)가 빠진 채 구현이 진행되어, 중간에 수정이 반복되고 앱 방향이 흔들렸다.

이를 바로잡기 위해 **노션에 기능 하나의 기준 기록을 시범으로 만들고**, 그 기록을 보고 앞으로의 작업 방식(지침)을 결정한다.

- 대상: 사용자 본인(최종 검토자)
- 결과물: 노션 기준 기록 1개 — Why, 하지 않을 것, 정책(사용자가 노션에서 직접 검토·수정), 디자인·코드(PR)·배포 상태
- 시범 기능: QR 출퇴근 (정책·화면·코드·배포가 모두 걸린 최근 기능)
- 성공 기준: 그 기록만 보고 "왜 만드는지 / 지금 어느 단계인지 / 내가 결정할 것"이 바로 판단되고, 노션 방식을 계속 쓸지 결정할 수 있다.

## 앞으로 지침에 반영할 제약 (시범 후 확정)

- 동시에 진행하는 작업 수를 제한한다.
- 기획 / 구현 / 검토는 서로 다른 세션이 맡는다.
- 구현 세션은 테스트 전에 어떤 테스트를 할지 먼저 보여 준다.
- 검토는 intent 부합과 코드 품질을 둘 다 본다.
- 병합·배포·완료 처리는 사용자 지시로만 한다.
