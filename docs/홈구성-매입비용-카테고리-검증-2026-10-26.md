# 매장 홈 구성 · 매입/비용 UI · 카테고리 — 2026-10-26

## 반영한 동작

- 홈의 오픈 준비 / 영업 중 / 마감 정리 바로가기를 관리자가 단계별로 선택한다. 선택 순서대로 표시하며 비어 있는 단계는 숨긴다. 최초 홈에 설정 진입을 제공하며 이후 같은 위치에서 수정한다. 미설정 매장은 기본 구성을 사용한다.
- 매장 공통 설정이지만 기존 사용자 권한을 우선한다. 손익 공유 미허용·파트타이머의 재무 탭 바로가기는 설정에 있어도 노출하지 않는다. 급여·출퇴근 기능 범위는 변경하지 않았다.
- 3단계 선택 → 최종 검토 → 적용. 검토에서 개별 수정 후 바로 검토로 복귀, 저장 연타 방지, 실패 시 선택 보존, 작성 중 이탈 확인을 제공한다.
- 매장/계정/역할별 Query 키를 사용하며 활성 홈은 30초마다 재조회하고 화면 복귀 시에도 갱신한다. 동시 관리자 수정은 마지막 저장이 적용된다.
- 매입·비용에 공통 LedgerHeader / LedgerFilters를 적용했다. 월 이동·금액 요약·분류 필터·목록의 위계와 글래스 카드, 배경을 통일했다. 매입 날짜 달력과 비용의 기존 고정비 권한·전월 적용 동작은 유지한다.
- POS 연동 버튼은 15pt 굵은 채움 버튼에서 13pt 보조 버튼으로 변경했다. 최소 44pt 터치 높이는 유지한다.
- 매입에 카테고리 관리(추가·이름 변경·삭제)와 카테고리 필터를 연결했다. 기존 카테고리 RPC/서비스를 재사용하며 구매처 유형 필터와 구분한다.
- 재고 칩은 저장된 카테고리와 실제 품목 분류를 함께 표시한다. 빈 카테고리 선택을 유지하고, 오류·남은 페이지·실제 빈 상태를 구분한다.
- 카테고리 조회의 매장 전환 시 이전 응답 혼입과 미처리 오류를 보완했다. 관리 모달은 스크롤·키보드 회피·추가 버튼 접근성 이름을 제공한다.
