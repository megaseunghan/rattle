## PM/PL 완료 기준

42개 라우트 명세 누락 0 (2026-10-29 S42 추가)과 9개 공통·모달 흐름(M08 레거시 발주 제외)을 관리한다. 완료는 ① 기능별 정상·오류·빈 상태 ② 입력 경계 ③ 취소/중단 ④ 중복·지연 ⑤ 역할별 서버 권한 ⑥ 원천 데이터 검산이 대상 플랫폼에서 증거와 함께 통과한 상태다. 현재 목표 전체 E2E는 미완료다. 실제기기·시뮬레이터·웹 결과는 각각 기록한다. 코드 변경/버그 수정은 다음 작업으로 분리한다.

### S19 후속 일별 근무 시나리오 (구현 후 네이티브 검증 대기)

파트타이머 본인 → 근무일·분·근거 제출 → 관리자 직원 근무시간에서 확인 → 월 급여 반영 → 명세·정산 확인. 시급 변경 전후 날짜를 각각 저장해 일급 합계 대조, 기존 날짜 수정 시 당시 시급 유지, 재제출 시 정산 해제와 원본 보존, 타인/타 매장/승인 취소 계정 접근 거절을 검증한다. 기존 월 합계 기록은 날짜별 자동 분할하지 않는다. SQL 선행 적용이 필요하다.

### S42 추적 보완 기록 · 2026-10-29

코드 자체 대조로 S42와 HOME_CONFIG를 추가했다. 기존 시나리오 ID는 변경하지 않았다. 화면 테스트의 정상 단계·직원 제한은 mock 근거이며 오류/지연/원격 권한/실기기 검증 완료로 확대하지 않는다. 전용 QA 매장 저장을 포함하는 위 절차는 향후 승인된 테스트 범위에서 실행하며, 이번 문서 수정에서는 운영 자료를 변경하지 않았다.
