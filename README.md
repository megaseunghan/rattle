# Rattle

소규모 식당/카페 사장님을 위한 모바일 관리 앱

## 주요 기능

현재 코드에 구현된 화면·계산·연동 범위와 배포 전 확인 사항은 [현재 구현 기능](docs/현재-구현-기능.md)에 정리했습니다.

- **매출 관리** — Toss Place POS 주문 조회·동기화 및 수기 매출 등록
- **재고 관리** — 식자재 재고 현황 및 품절 임박 알림
- **레시피 관리** — 레시피별 원가/마진율 자동 계산
- **대시보드** — 매장별 매출·손익과 전체 매장 합산 현황
- **매입·인건비** — 매입 내역과 직원별 급여 관리

## 근무시간과 급여 작성

Rattle에는 파트타이머의 직원별·월별 총 실근무 분을 입력하고, 월급제 정규직은 근무 분 없이 급여를 작성한다.

1. 파트타이머는 직원관리에서 월과 직원을 선택하고 **근무시간 입력**을 누른다.
2. 휴게시간을 제외한 총 근무 분, 적용 시급, 입력 근거를 작성한다. 예: `9600분 = 160시간`.
3. 정규직은 **급여 계산**으로 해당 월 급여를 작성한다. 근무시간 입력은 필요 없다.
4. 파트타이머의 입력 분·세전 금액을 확인한 뒤 정산을 확정한다. 정산 전에는 모든 재직자의 급여가 작성돼 있어야 한다.

파트타이머의 근무 분 미입력과 0분은 구분한다. 0분은 입력 완료로 처리한다. 세전 금액은 `총 분 × 적용 시급 ÷ 60`을 원 단위 반올림하며, 정규직 월급 계산은 유지한다. 기존 정규직 근무 분이 있으면 삭제하지 않고 선택 정보로 보존한다. 적용 시급에는 수습 등 지급 조건을 반영한다. 월중 시급 변경은 기간별 세전 합계로 계산한 적용 시급(소수 넷째 자리까지)을 입력하고 최종 세전 금액을 검산한다. 수정 사유와 작성 계정, 변경 전후 값은 DB 이력에 보관하며 변경 시 정산 확정을 해제한다.

### 기존 DB 전환

앱 업데이트 전에 `supabase/migrations/20261016_manual_work_minutes.sql`, `supabase/migrations/20261018_part_time_minutes_settlement.sql`을 순서대로 검증 환경에서 실행한 뒤 대상 운영 DB에 적용한다. 첫 마이그레이션을 이미 적용한 DB에는 두 번째 마이그레이션만 적용한다. 기존 출퇴근 데이터는 삭제하지 않으며 파트타이머 월별 분·금액을 이전한다. 기존 급여 금액과 정규직의 과거 근무 분은 보존하고, 출퇴근에서 새로 생성된 급여는 공제 검토가 필요하다. 이력 초기 상태도 함께 보관한다.

전환 후 월별 파트타이머 근무 분·세전 합계를 기존 출퇴근 집계와 대조한다. 직원 삭제, 다른 계정의 이력 수정 거부, 동시 수정 충돌, 근무 분 수정 후 정산 해제를 DB에서 확인한다. 전환 실패 시 트랜잭션 전체가 롤백된다. 앱만 먼저 업데이트하면 새 컬럼·이력 테이블이 없어 저장할 수 없다. 네이티브 위치 권한 제거는 의존성 재설치 및 네이티브 프로젝트 재생성 후 새 빌드에서 확인한다.

## 기술 스택

- [Expo](https://expo.dev) SDK 55 + Expo Router
- React Native 0.83 / React 19
- TypeScript
- [Supabase](https://supabase.com) (Auth + PostgreSQL + RLS)

## 시작하기

### 1. 의존성 설치

```bash
npm install
```

### 2. 환경변수 설정

`.env` 파일 생성:

```
EXPO_PUBLIC_SUPABASE_URL=your_supabase_url
EXPO_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 3. DB 스키마 적용

Supabase SQL Editor에서 `supabase/schema.sql` 실행

### 4. 앱 실행

```bash
npm start        # Expo dev server
npm run ios      # iOS 시뮬레이터
npm run android  # Android 에뮬레이터
```

## 프로젝트 구조

```
app/          # 라우트 (expo-router)
├── (auth)/   # 로그인, 매장 선택
└── (tabs)/   # 홈, 재고, 매입, 인건비 (매출 화면은 app/pos/)
lib/
├── contexts/ # AuthContext
├── hooks/    # 도메인별 커스텀 훅
├── services/ # Supabase DB 접근 레이어
└── components/
types/        # 전역 타입 정의
supabase/     # DB 스키마
```
